## Installation

1. Clone the repository.
2. Create a virtual environment.
3. Install the dependencies.
4. Set up the database.

```shell
pip install -r requirements.txt
python manage.py migrate
```

## Database

Para desenvolvimento execute no shell:

```shell
docker-compose up -d
```
